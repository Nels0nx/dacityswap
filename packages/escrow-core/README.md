# @dacityswap/escrow-core

The escrow state machine, fee engine and settlement maths behind
[DacitySwap](https://github.com/Nels0nx/dacityswap). Pure TypeScript, no dependencies,
about 700 lines.

> **Status:** 0.2, complete and tested, not yet published to npm. Use it from the repository.
> The API may still change before 1.0.

## What it does

- **Prices a trade.** `quote()` returns what the buyer pays, what the seller receives and what
  the platform earns, in integer minor units, with one rounding rule.
- **Runs an order.** `applyEvent()` moves a record along the declared transitions and throws on
  anything else. Every state that holds money has a deadline.
- **Checks who is acting.** `applyEventAs()` refuses an event from a role that may not send it.
- **Settles.** `settle()` accounts for every cent of a finished trade, including split rulings.
- **Verifies.** `verifyRecord()` replays an order's history and says whether its state follows.

Every function is pure: no clock, no I/O, no mutation. The clock is an argument.

## Example

```ts
import { quote, createEscrow, applyEventAs, tick, settle } from '@dacityswap/escrow-core';

const priced = quote({ unitPriceMinor: 21_900, currency: 'EUR', method: 'card' });
// totalMinor 23129, sellerPayoutMinor 20805, platformRevenueMinor 1643

let order = createEscrow({ id: 'esc_1', quote: priced, now: new Date() });
order = applyEventAs(
  order,
  { type: 'PAYMENT_CAPTURED', paymentRef: 'pay_1' },
  'system',
  new Date(),
);
order = applyEventAs(order, { type: 'SELLER_ACCEPTED' }, 'seller', new Date());
order = applyEventAs(order, { type: 'SELLER_MARKED_DELIVERED' }, 'seller', new Date());

// On a schedule: pays the seller once the buyer's 24 hours have passed without a dispute.
order = tick(order, new Date());

settle(order); // null while open; who received what once it is final
```

## States

```
awaiting_payment ──► funded ──► in_delivery ──► delivered ──► completed
       │               │             │              │
       ▼               ▼             ▼              ▼
   cancelled        refunded ◄──────────────── disputed ──► completed | refunded | split
```

| Waiting for           | Default window | If it passes          |
| --------------------- | -------------- | --------------------- |
| The buyer to pay      | 30 minutes     | The order lapses      |
| The seller to accept  | 12 hours       | The buyer is refunded |
| The seller to deliver | 24 hours       | The buyer is refunded |
| The buyer to confirm  | 24 hours       | The seller is paid    |
| The arbiter to rule   | 14 days        | The buyer is refunded |

## Develop

```bash
pnpm --filter @dacityswap/escrow-core test        # 49 tests
pnpm --filter @dacityswap/escrow-core typecheck
pnpm --filter @dacityswap/escrow-core build       # dist/: ESM, CommonJS and types
```

`vectors/settlement.json` is generated by these tests and read by the contract's, so the two
implementations cannot drift apart unnoticed. Regenerate it with
`UPDATE_VECTORS=1 pnpm --filter @dacityswap/escrow-core test`.
